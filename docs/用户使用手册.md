# 用户使用手册

## 一、登录
1. 打开浏览器访问系统
2. 默认账号: admin / Admin@ChangeMe2026
3. 首次登录需修改密码

## 二、仪表盘
- 数据统计：年级/班级/学生/考试数量
- 最新考试：最近考次得分率
- 科目统计：各科均分对比
- 班级排行：年级内排名
- 风险学生：持续退步名单

## 三、学生管理
- 树状列表：年级 → 班级 → 学生
- 展开全部/折叠全部
- 悬停节点可操作
- 支持搜索和Excel导入

## 四、考试管理
- 创建/编辑/删除考试
- 设置考试科目及满分
- 按年级/类型过滤

## 五、成绩录入
- 选择考试 → 加载学生 → 录入
- 支持键盘操作
- Excel模板导入/导出

## 六、数据分析
- 考试分析：各科均分/分布/班级对比
- 学情跟踪：历次趋势/优势/薄弱科目
- 班级分析：整体表现/历次考试

## 七、AI助手
- 在分析页面打开AI对话
- 自动获取上下文数据
- 支持多轮对话
- 需配置LLM_API_KEY

## 八、系统管理
- 用户管理：添加/编辑/删除用户
- 科目管理：维护科目
- 年级/班级管理
