# 数据库备份指南

## 手动备份
```bash
docker exec exam_postgres pg_dump -U examuser examdb > backup_20260728.sql
```

## 自动备份（Linux crontab）
```bash
# 每天凌晨3点备份
0 3 * * * cd /path/to/project && docker exec exam_postgres pg_dump -U examuser examdb > backups/$(date +\%Y\%m\%d).sql && find backups -name "*.sql" -mtime +30 -delete
```

## 备份脚本（Windows）
使用本项目提供的 `docker/backup.bat`，通过任务计划程序设置定时执行。

## Docker Compose 数据卷
数据库数据存储在 Docker 卷 `postgres_data` 中，备份该卷可快速恢复。
