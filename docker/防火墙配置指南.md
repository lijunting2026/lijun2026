# 服务器防火墙配置指南

> 适用场景：Docker 部署到局域网或公网服务器
> 系统要求：Windows Firewall / iptables / firewalld

---

## 一、端口说明

| 端口 | 服务 | 是否需要对外开放 | 说明 |
|------|------|-----------------|------|
| **80** | Nginx（前端） | ✅ 必须开放 | 用户通过浏览器访问系统 |
| **443** | HTTPS（可选） | ⚠️ 公网部署建议开放 | 配置 SSL 证书后使用 |
| **8000** | FastAPI 后端 | ❌ 不开放 | 仅 Nginx 内部反向代理访问 |
| **5432** | PostgreSQL | ❌ 不开放 | 仅后端容器内部访问 |
| **22** | SSH | ⚠️ 按需开放 | 服务器远程管理，建议修改默认端口 |

---

## 二、Windows Server 防火墙配置

### 开放 80 端口（Web 访问）
```powershell
# 开放 HTTP 端口
netsh advfirewall firewall add rule name="考试质量分析系统-HTTP" dir=in action=allow protocol=TCP localport=80

# 开放 HTTPS 端口（如配置了 SSL）
netsh advfirewall firewall add rule name="考试质量分析系统-HTTPS" dir=in action=allow protocol=TCP localport=443

# 限制 SSH 端口仅允许内网（按需）
netsh advfirewall firewall add rule name="SSH-仅限内网" dir=in action=allow protocol=TCP localport=22 remoteip=192.168.0.0/16,10.0.0.0/8
```

### 查看已配置的规则
```powershell
netsh advfirewall firewall show rule name=all verbose | findstr "考试质量分析系统"
```

## 三、Linux 防火墙配置

### 使用 firewalld（CentOS / RHEL / Rocky）
```bash
# 开放 80 端口
firewall-cmd --permanent --add-port=80/tcp

# 开放 443 端口（HTTPS）
firewall-cmd --permanent --add-port=443/tcp

# 重启防火墙使生效
firewall-cmd --reload

# 查看已开放端口
firewall-cmd --list-ports
```

### 使用 iptables（Ubuntu / Debian）
```bash
# 开放 80 端口
iptables -A INPUT -p tcp --dport 80 -j ACCEPT

# 开放 443 端口
iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# 保存规则
iptables-save > /etc/iptables/rules.v4
```

## 四、安全加固建议

### 1. 限制来源 IP（局域网部署）
仅允许内网 IP 访问 Web 服务：
```bash
# firewalld
firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="192.168.1.0/24" port protocol="tcp" port="80" accept'

# iptables
iptables -A INPUT -p tcp --dport 80 -s 192.168.1.0/24 -j ACCEPT
iptables -A INPUT -p tcp --dport 80 -j DROP
```

### 2. Docker 内部网络
确认 Docker Compose 中已配置内部网络（已默认配置）：
```yaml
networks:
  exam_network:
    driver: bridge
```
后端和数据库都加入 `exam_network`，不映射端口到宿主机即可隔离。

### 3. 定期检查
```bash
# 查看所有监听端口
netstat -tlnp

# 查看防火墙状态
# Windows
netsh advfirewall show allprofiles

# Linux
firewall-cmd --list-all
```

### 4. 安全 Checklist（补充到部署教程）
- [ ] 除 80（及 443）外，所有端口已防火墙拦截
- [ ] SSH 已限制来源 IP 或修改了默认端口
- [ ] 服务器未开放不必要的管理端口（如 3306、5432、6379 等）
- [ ] Docker 容器未暴露不必要的端口到宿主机
