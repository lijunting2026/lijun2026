# 日志与监控指南

## 一、日志系统

### 日志文件位置（Docker 环境）
```
logs/
├── app.log          # 所有 INFO 及以上级别的日志
├── app.log.1        # 轮转后的历史日志
└── error.log        # 仅 ERROR 级别错误日志
```

### 日志文件位置（本地开发）
```
backend/logs/
├── app.log
└── error.log
```

### 日志轮转策略
- 单个文件最大 10MB
- app.log 保留最近 5 个备份
- error.log 保留最近 3 个备份

### 查看日志
```bash
# Docker 环境
docker-compose logs -f           # 实时查看所有服务日志
docker-compose logs -f backend   # 只看后端日志
docker logs exam_backend         # 直接查看容器日志

# 进入容器查看应用日志
docker exec exam_backend cat logs/app.log
docker exec exam_backend tail -f logs/app.log
```

## 二、运行状态

### 健康检查
系统提供了 `/health` 端点，可用于监控：
```bash
curl http://localhost:8000/health
# 返回示例：
# {
#   "status": "ok",
#   "app": "考试质量分析系统",
#   "version": "1.0.0",
#   "timestamp": "2026-07-28T12:00:00",
#   "python": "3.11.x",
#   "debug": false,
#   "llm_enabled": true
# }
```

### Docker 容器状态
```bash
# 查看所有容器状态
docker-compose ps

# 查看资源使用
docker stats exam_backend exam_frontend exam_postgres
```

## 三、监控建议

### 1. Uptime Kuma（推荐）
部署 Uptime Kuma 来监控服务可用性：
```bash
docker run -d --name uptime-kuma -p 3001:3001 louislam/uptime-kuma
```
然后添加监控项：`http://服务器IP:8000/health`

### 2. Prometheus + Grafana（进阶）
如需更全面的监控，建议：
1. 在 FastAPI 中添加 `prometheus-fastapi-instrumentator` 包
2. 用 Prometheus 采集指标
3. 用 Grafana 展示仪表盘

### 3. 告警规则建议
- 健康检查连续 3 次失败 → 服务宕机告警
- 磁盘使用率 > 80% → 清理旧日志或扩容
- 5xx 错误率 > 5% → 检查应用错误日志
